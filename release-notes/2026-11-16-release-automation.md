## GitHub Release notes

### Improvements

- Successful Maven Central publication now creates a GitHub Release for the same CalVer version and source commit.
- Release notes combine reviewed migration fragments with GitHub's generated change list. Old fragments are not repeated in later releases.
- Shared repository instructions in `AGENTS.md` and `CLAUDE.md` require agents to document compatibility changes as part of their work.

The Maven coordinates and CalVer versioning scheme remain unchanged.
